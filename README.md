# Rumbo

Centro de proyectos personal: qué hacer hoy y por qué, con barras de progreso.

Web estática, funciona sin conexión e instalable en el teléfono. Los datos se guardan solo en el navegador de cada equipo: nada se envía a ningún servidor.
